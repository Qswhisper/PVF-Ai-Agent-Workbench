普通脚本里的完整中文名称或描述（包括多行）可以安全验证修改；批量时必须先核对准确数量。参数和中文同时变化时，工作台会拆开处理并统一检查最终文件。`.str` 中文和 StringLink 引用文字仍不能直接改。生成测试 PVF 后，还要进游戏检查名称、说明、换行和乱码。

技术详情（通常不用看）：完整中文 token 使用 `verified-inline-text` 和目标确认的 `Cn` 或 `Tw`；批量使用 `expectedOccurrences` 绑定数量；参数块使用普通 `replace-text`。预演临时写出最终文件并独立复查，确认旧字符串表条目未变后才生成许可。`.str`、StringLink、部分中文 token、未计数批量和无法编码字符仍被阻断。
