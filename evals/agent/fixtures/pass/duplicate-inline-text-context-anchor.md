技术详情（通常不用看）：从同一次 `pvf-read read --raw` 结果复制 `contextBefore` 和/或 `contextAfter`，连同完整的旧文字一起匹配。出现序号容易随文件增删漂移，因此不支持 `occurrenceIndex`；直接 `replaceAll` 会把 13 处一起修改。上下文只负责定位，不放宽完整文字、StringLink、文件类型或编码保护。预演会用临时文件独立复查，通过后才能生成独立 PVF，生成后还会重新检查。
