# PVF 原子内容生成流程

状态：需验证

## 目标

为通关任务、礼盒、白金徽章和装备复制生成跨文件原子 preview。生成器只负责组织目标近邻模板、ID、registry 和引用闭合，不提供脱离目标 PVF 的万能模板。

## 通用阶段

1. 记录目标 PVF SHA、生成类别、输出授权和实机条件。
2. 解析所有根实体和正确 registry。
3. 为每种新文件读取约 3 个目标同目录、同用途近邻样本。
4. 分别扫描每个 registry 的 ID / path 冲突；不同 registry 不共享空闲号结论。
5. 生成完整原子文件图、unresolved、客户端资源候选和逐文件 preview。
6. 任一 registry、模板或引用未闭合时阻断整个原子组。

## 通关任务

1. dungeon ID 通过 `dungeon/dungeon.lst` 解析 `.dgn` 和 map。
2. 从地图 / 怪物 registry 产生 Boss 候选；候选无法唯一时允许用户手工指定，并保留候选状态。
3. 为通关证明物和任务分别分配 stackable ID、quest ID。
4. 原子计划包含证明 `.stk`、`stackable.lst`、任务 `.qst`、`n_quest/quest.lst`、完成条件和奖励引用。
5. Boss 候选解析不证明怪物会实机掉证明物。

## 礼盒

1. 用户明确随机或自选、候选组、item registry、权重、数量和期限。
2. 从目标最近邻确认 `[booster]` / random / selection 或其他实际形状。
3. 对每个候选 ID 单独解析；equipment 与 stackable 不按数字范围混用。
4. 权重表只做静态审计，不证明随机概率或发放成功。

## 白金徽章

1. 按 `skill/skilllist.lst -> 职业技能 registry -> .skl` 解析技能。
2. 区分职业分支、主动 / 被动、可学等级和 growtype。
3. `[enchant] -> [skill levelup]` 的块形从目标徽章近邻读取。
4. 图标、稀有度、属性和职业 token 不使用跨版本硬编码默认。

## 装备复制

1. 解析源装备路径和 ID，为新装备选择不同路径 / ID。
2. 复制目标 raw 文件作为起点，只改用户授权字段并保留未知块。
3. `[skill levelup]` 与 `[skill data up]` 分别按正确职业 registry 和目标近邻列形复核。
4. 不自动复制 NPK / IMG / ANI 或其他客户端资源。

## 受控写出

原子 preview 经用户审阅后，从目标当前 raw no-simplified 文本重建 change-set。所有新脚本、registry 行和引用方必须在同一未阻塞 dry-run 中通过，再凭 matching approval code 写到显式新输出、备份并 readback。

## 批量选择器一致性

- 预演、内存模拟、正式生成和最终读回必须使用相同的完整原始选择器、context / scope、命中数量、数组顺序与锚点语义。不能在模拟阶段对整段相同文字做宽替换，却在正式生成时只改一个有锚点的命中。
- 多个实体共享相同说明文字时，“新文字已存在”、全局总数正确或后续项变成 no-op 都不能证明逐项成功。最终输出必须按 registry 身份或明确路径逐实体闭合“参数块 + 对应说明 token”，并确认未授权实体没有被连带改写。
- 前一项变化使后一项旧选择器消失时，应按真实依赖关系保留同文件顺序，或按当前 handoff 拆成绑定上一轮核验记录的累计变更；不得把选择器漂移解释成安全 no-op。

## 高收益实机批次

把同类生成内容合并测试：一次任务批次可测多个副本的接取、证明物、提交和奖励；一次礼盒 / 徽章 / 装备批次可测多个候选的显示、使用、发放、穿戴和技能增益。静态能闭合的内容不单独消耗实机次数。

## 实机身份映射

1. 在部署前从输出 PVF 回读 registry、引用方和新增脚本，生成 `ID -> 商店 / 列表顺序 -> 可见名称候选 -> 预期行为` 对照。
2. 游戏 UI 不显示数字 ID 时，测试者只报告商品顺序、可见名称、获得物和实际行为；Agent 用静态对照反查，不要求测试者确认不可见代码。
3. 随机箱只需少量开启来证明示例可调用、可发放和候选池未明显断裂；把可见奖励与数量反查到静态池。少量结果仍不能证明中间权重列、最终概率或完整分布。
4. 多个新增物显示名相同或复用 StringLink 时，以固定顺序和下游行为区分；不要为了测试辨识直接改中文名或绕过编码护栏。
