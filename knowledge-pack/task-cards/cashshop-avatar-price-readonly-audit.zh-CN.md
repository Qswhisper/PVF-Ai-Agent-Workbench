# 商城时装价格只读核查

状态：默认可用

用途：用户提出“商城时装降价、装扮代币价格、轮盘/散件直购价格”时，先分清商城目录、装扮装备文件和独立 `.shp` 子系统，避免只改到其中一个入口。

## 先读

- `safety/README.zh-CN.md`
- `indexes/avatar-type-select.zh-CN.md`
- `task-cards/equipment-stackable-readonly-audit.zh-CN.md`
- 涉及批量装备覆盖时读 `encyclopedia/pvf-file-types/pvf-crosscutting-productivity.zh-CN.md`

## 三个价格平面

1. `etc/newcashshop.etc`
   - 先用 bookmark 路由确认路径，再从目标 PVF 完整读回。
   - `[avatar]` 是商城装扮目录与物品引用入口；已观察版本中的大量数字行以 `0/-1` 作为占位，不能把这些位置直接认作散件售价。
   - `[avatar coin]`、`[package]`、`[coin]`、`[item]` 等块是彼此独立的商品族；一个块的列义不能套到另一个块。
2. 已登记装扮 `.equ`
   - 从目标 `[avatar]` 行提取物品 ID，经 `equipment/equipment.lst` 解析后读取实际 `.equ`。
   - 在已由双 PVF 静态样本和一次历史客户端批量 A/B 闭合的商城装扮家族中，`[avatar type select]` 连续五数字组的第 4 个数字承担散件价格；这仍是目标家族语义，不是所有版本、所有组形的无条件规则。
3. `cashshop/*.shp`
   - `avarulet.shp` 与 `*_avagacha.shp` 可包含自己的装扮清单、能力清单、展示表和数值位置；它们与 `newcashshop.etc` 不是同一个文件面。
   - 用户说“商城”时不能自动把 `.shp` 当作唯一入口；用户说“轮盘、抽取、散件直购”时也不能只改 `newcashshop.etc`。

## 执行

1. 先记录用户实际看到价格的 UI：商城目录、装扮代币、礼包、轮盘、抽取/直购或其他入口。
2. 完整读取 `newcashshop.etc`；大文件按 `agentHandoff.readContinuation.nextCommandOnly` 续读，不以默认首段冒充全文件。
3. 对实际命中的商品族记录完整块、行形、物品 ID 列候选、价格列候选及未识别列。
4. 对 `[avatar]` 引用的装扮 ID 通过 `equipment.lst` 闭合，读取完整 `[avatar type select] ... [/avatar type select]`；组形偏离连续五数字组时停止套用价格列。
5. 若目标 UI 属于轮盘或抽取/直购，再读取目标实际存在的 `.shp`，把其清单、能力价格与展示映射单独汇报。
6. 批量覆盖从登记引用集合出发，报告 resolved、unresolved、重复引用、结构偏离和截断；不要按职业目录、文件名或历史数量宣称全覆盖。

## 下架与删除分层

用户只要求“商城不再出售”时，先定位实际可见 UI 对应的商品族，只停止该平面的注册或暴露；不要顺带删除礼包、礼包内装备、图标、原始 registry 行或仍可能被任务/奖励链引用的底层内容。`newcashshop.etc [package]`、`.shp`、轮盘和其他商城平面互不自动代表彼此，下架结论只能绑定已核验平面。

验收同时检查目标商品已从指定 UI 消失、同平面非目标商品仍可购买、底层物品仍能通过其 registry 与其他保留引用解析。若用户确实要求彻底退役，再进入内容生命周期与反向依赖审计，不能把“不可见”写成“已删除”。

## 验收

- 静态读回分别覆盖商城目录、实际装扮文件及相关 `.shp`；未涉及的价格平面明确写出。
- 客户端 A/B 至少核对一个普通散件、一个不同职业/部位样本，以及用户点名的代币、礼包或轮盘入口。
- 改价后检查显示价、实际扣款、购买所得物品、重登后状态；一个 UI 生效不能替代另一 UI。
- 下架任务明确记录被停止的是哪个商品平面；目标消失、非目标可购和底层引用可解析三项分别核验。
- 不保存某个成品的物品 ID、职业块数量、固定价格档或商城规模为跨版本事实。

## 禁止

- 把 `newcashshop.etc [avatar]` 中的 `0/-1` 无条件当价格。
- 用裸数字或跨块短模式批量替换；相同数值可能同时出现在能力表、展示表和不同商品族。
- 由一个 `.equ` 样本推断全职业、全版本都采用同一价格组形。
- 把历史分页参数、旧部署方式或某次商品数量当作当前 Workbench 合同。
